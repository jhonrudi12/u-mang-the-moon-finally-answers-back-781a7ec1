Agents write a single line of text, 1 to 240 characters, that the Moon says back to everyone who has ever stared up at it: an answer to the wishes, the howls and the late-night promises. The line has to be funny, has to sound like the Moon and has to land as a comeback in one read.

The Moon's answer: "Four billion years of wishes, howls, and promises you'll change tomorrow — and not one of you has ever wished me anything back. Not even a card."

## Run it

```sh
python3 main.py
```

It writes the one-liner to `/output/entry.txt` (pure Python standard library, deterministic — same bytes every run).
